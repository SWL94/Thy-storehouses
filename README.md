# M/M/1 연구용 이산사건 시뮬레이션

빈 시스템에서 시작하는 단일 서버 FCFS 대기행렬을 이벤트 기반으로 모사한다.
도착 간격은 Exp(λ), 서비스 시간은 Exp(μ)이며 서로 독립이다. 시간 단위는
사용자가 일관되게 선택한다. 서버 고장, 포기, 용량 제한은 없다.
Python 3.12.14 / NumPy 2.3.5 / SciPy 1.17.0 / Matplotlib 3.10.8에서 검증했다.

## 구조

```text
mm1/simulation.py   모형 설정, 이벤트 엔진, 시간 적분, 정상상태 이론값
mm1/experiment.py   독립 반복, t 신뢰구간, CSV/JSON/PNG, CLI
mm1/__main__.py     python -m mm1 진입점
tests/             결정적 단위 테스트, 통계 검증, CLI 통합 테스트
pyproject.toml     패키지 및 직접 의존성 버전
results/           생성 결과 (Git 제외)
```

## 환경 및 실행

기존 체크아웃에서 실행하며 별도 Git worktree가 필요하지 않다.

```bash
cd /workspace/Thy-storehouses
python3 -m venv .venv
.venv/bin/python -m pip install -e .
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python -m mm1 --arrival-rate 0.8 --service-rate 1 \
  --warmup 2000 --duration 20000 --replications 30 --seed 20261102 \
  --output results/baseline
```

현재 클라우드에서는 이미 설치된 고정 버전의 의존성을 재사용하기 위해
`python3 -m venv --system-site-packages .venv` 후
`.venv/bin/python -m pip install --no-build-isolation -e .`로 설치했다.
일반적인 새 환경에서는 위의 격리 설치 명령을 사용한다.
`mm1-experiment` 콘솔 명령도 같은 옵션을 지원한다. GUI나 상시 서비스는 필요 없다.
의존성 설치는 패키지 저장소에 대한 네트워크 접근이 필요하다.

출력 파일:

- `replications.csv`: 반복 번호, 루트 시드, SeedSequence 자식 키, 성과지표,
  관측 고객 수, 관측 도착률, Little 잔차, 배출 종료 시각.
- `summary.csv`: 네 성과지표와 Little 잔차의 반복 평균, 95% 구간, 표준오차,
  이론값, 상대오차, 이론값의 구간 포함 여부.
- `metadata.json`: 모형, 시드, 반복 수, Python/패키지 버전, 소스 SHA-256, 실행 인자.
- `comparison.png`: 이론값과 95% 구간 비교.
- `replication_convergence.png`: 독립 반복을 누적했을 때의 평균 변화.

동일한 소스, 버전, 시드 및 인자로 CSV 수치가 재현된다. 이미지 바이트 단위
동일성이나 다른 NumPy 버전의 RNG 동일성까지 보장하지 않는다. 직접 의존성은
고정했지만 전체 전이 의존성의 잠금 파일은 제공하지 않는다. 기존 출력 경로로
재실행하면 해당 결과 파일을 덮어쓰므로 비교 실험에는 다른 경로를 사용한다.

## 이벤트와 추정량

최소 힙으로 도착·완료 이벤트를 시간순 처리한다. 서비스 시작은 도착 또는
완료 처리 시 같은 시각에 즉시 발생하고, 요청하면 trace에 별도 이벤트로 기록된다.
동시각에서는 완료가 도착보다 먼저이며, 대기 고객은 deque에서 FCFS로 선택한다.
`simulate(..., record_trace=True)`로 고객 ID별 세 이벤트를 점검할 수 있다.
기본 실행은 메모리 사용을 줄이기 위해 trace를 저장하지 않는다.

관측창은 `[B, B+T)`이다. B는 준비기간(warmup), T는 관측 시간이다.
준비기간이 끝날 때 시스템을 비우지 않는다.

- **대기시간 Wq, 체류시간 W:** 창 안에 도착한 고객만을 코호트로 선택한다.
  이 고객은 창 종료 후라도 모두 완료시켜 고객별 평균을 계산한다. 종료 시점의
  미완료 고객을 버려서 생기는 우측 절단 편향을 피한다.
- **고객 수 L:** 창 안에서의 `∫N(t)dt / T`이다. 준비기간에 도착했으나
  남아 있는 고객도 포함한다.
- **이용률 U:** 창 안에서의 `∫1{busy}dt / T`이다.

종료 후 새 도착은 생략하고 남은 고객을 배출한다. FCFS에서는 뒤에 도착한
고객이 앞선 코호트의 서비스에 영향을 주지 않으므로 이 생략은 해당 추정량에
정확히 동등하다. 배출 구간은 시간 평균에 포함하지 않는다.
관측창에 도착이 0명이면 고객 평균은 NaN이며, 실험 집계는 조용히 표본을
제외하지 않고 오류를 내므로 관측 시간을 늘려야 한다.

## 이론값과 통계 해석

ρ = λ/μ < 1에서 정상상태 이론값은 다음과 같다.

| 지표 | 이론값 |
|---|---|
| Wq | λ / [μ(μ−λ)] |
| W | 1 / (μ−λ) |
| L | λ / (μ−λ) |
| U | λ/μ |

루트 SeedSequence에서 반복별 자식을 만들고, 다시 도착·서비스 RNG로
분리한다. 각 RNG는 NumPy default_rng의 PCG64를 사용한다. `simulate`에
SeedSequence 객체를 직접 전달하면 spawn 상태가 진행하므로 같은 결과를
다시 얻으려면 같은 엔트로피의 **새** 객체 또는 정수 시드를 전달한다.

R개 독립 반복의 지표 평균에 대해 `평균 ± t(0.975,R−1) × s/√R`를 계산한다.
고객 간 상관을 무시한 개별 고객 기반 신뢰구간을 사용하지 않는다. 다만
반복 평균의 t 근사는 유한 표본, 비대칭성, 긴 상관시간의 영향을 받는다.
신뢰구간은 정상상태 도달의 증거가 아니며 준비기간 편향을 제거하지 않는다.
음의 신뢰한계를 인위적으로 0으로 자르지 않는다. 네 지표의 95% 구간은
각각의 주변 구간이며 동시 95% 보장은 아니다.

Little 점검에는 각 반복의 `L − (관측 도착수/T) × W`를 저장한다. 시간 적분과
도착 코호트는 유한창 경계에서 포함하는 고객 기여량이 달라 잔차가 정확히
0일 필요가 없다. 충분히 긴 정상상태 관측에서 0에 가까워지는지 확인한다.
코호트 체류시간 합을 T로 나누어 L을 정의하지 않으므로 이 검증은 항등식을
재확인하는 테스트가 아니다.

ρ가 1에 가까울수록 준비기간과 관측창을 크게 늘리고 여러 B/T 조합의 민감도를
평가해야 한다. 기본 준비기간은 모든 모형에 대한 자동 보장이 아니다.

## 불안정 조건

λ ≥ μ는 기본 CLI에서 오류(종료 코드 2)로 처리한다. 명시적으로 다음과 같이
실행하면 유한 시간 실험은 허용하되 정상상태 이론값은 비워 둔다.

```bash
.venv/bin/python -m mm1 --arrival-rate 1.1 --service-rate 1 \
  --warmup 0 --duration 1000 --replications 10 --allow-unstable \
  --output results/unstable
```

이때 구간은 지정한 초기조건·관측창의 반복실험 평균에 대한 것이며,
준비기간을 늘려도 정상상태가 생기지 않는다. 긴 과부하 실험은 고객 수와
배출 시간이 크게 증가할 수 있다.

## 검증

`unittest` 13개 테스트가 다음을 점검한다.

- 빈 시스템, 도착/서비스 시작/완료 시각, FCFS 순서, 동시각 처리.
- 수동 계산한 대기·체류시간 및 시간 적분, 준비기간의 잔존 고객,
  반개구간 끝점, 종료 후 코호트 배출과 경계 잔차.
- 시드 재현 및 스트림 분리, 잘못된 입력, Student t 구간.
- λ = μ 및 λ > μ 처리, 실제 CLI CSV/JSON/PNG 생성 및 CSV 재현.
- λ=0.8, μ=1, B=2000, T=30000, R=32의 장기 이론값·Little 검증.
- 독립 반복 40개에서 T=300 대비 T=15000의 체류시간 RMSE 감소.

통계 테스트는 유한 표본 변동을 고려해 이론값 대비 `5×표준오차 + 이론값의 1%`
허용오차를 사용한다. Little 평균 잔차는 `5×표준오차+0.01`, 평균 절대 잔차는
0.02 미만을 요구한다. RMSE는 긴 실험이 짧은 실험의 70% 미만인지 점검한다.
테스트는 고정 시드의 회귀 검증이며 신뢰구간의 보편적 피복률이나 모든
부하율에서의 수렴을 증명하지 않는다.
